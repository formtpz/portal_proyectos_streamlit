# Portal de Proyectos

Portal de entrada para los sistemas Streamlit de Perú e Italia.

## Despliegue
1. Crear un repositorio nuevo en GitHub y subir `app.py` y `requirements.txt`.
2. En Streamlit Community Cloud, seleccionar **Create app**, conectar el repositorio y usar `app.py` como archivo principal.
3. Desplegar. No requiere secretos ni conexión a bases de datos.

El portal solo redirige a las aplicaciones existentes. El inicio de sesión se realiza en cada aplicación.
